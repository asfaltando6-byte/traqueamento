Sua biblioteca de pesquisa

Importe um JSON com até 200 anúncios no formato do modelo. O arquivo não consulta a Meta; as informações importadas são tratadas como manuais. Dados antigos não confirmam que um anúncio continua ativo hoje.

O modelo contém campos vazios para preencher, sem anúncios de demonstração. A exportação inclui favoritos e notas; a importação atual recebe os anúncios.

“Dias desde o início” usa a data declarada, sem comprovar veiculação contínua. Após 7 dias sem atualização, o status passa a não confirmado. Ofertas são agrupadas pela URL de destino sem UTMs; caminhos e IDs de produto permanecem separados.

Código para anúncios do Meta

O mesmo código funciona para todos os seus produtos e sites cadastrados

No Gerenciador de Anúncios, abra o anúncio em Editar → Rastreamento → Parâmetros de URL e cole este texto, sem ponto de interrogação:

utm_source={{site_source_name}}&utm_medium=paid&utm_campaign={{campaign.id}}&utm_content={{ad.id}}&utm_term={{adset.id}}
Campanha{{campaign.id}}
Conjunto{{adset.id}}
Anúncio{{ad.id}}

Os nomes são importados da Meta; os IDs fazem a ligação com as vendas. Mantenha a URL de destino no campo do site. Não cole a chave do painel ou tokens nos anúncios.
